# RPG audio samples

Author: Kenney. License: CC0; original notice retained in LICENSE.txt.
Official pack: https://kenney.nl/assets/rpg-audio
Downloaded mirror: https://opengameart.org/sites/default/files/RPGsounds_Kenney.zip
Each retained file and its SHA256 is listed in manifest.json.

Runtime mapping: scripts/game_audio.gd. Footsteps, sword swishes, metal impacts,
harvesting, construction, deliveries and selection use sampled OGG audio.
Ten voices maximum; per-event cooldown, pitch variation and camera/fog gating.
No hidden enemy sounds. Pause also pauses existing voices.
